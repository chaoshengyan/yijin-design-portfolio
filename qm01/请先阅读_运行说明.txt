QM-01·战术后勤 —— 运行说明
================================

一、正式入口
  index.html（完整扩展名 .html；双击此文件启动）

二、环境要求
  - 现代浏览器（推荐 Edge 最新版），无需安装任何软件、无需 Node/后端/代理。
  - 本地模式离线可用；语音识别需要 HTTPS 或 localhost（浏览器安全上下文限制）。

三、启动步骤
  1. 双击本目录下的 index.html 即可进入“战前准备”界面。
  2. 页面右下角圆形入口“QM-01 助手”打开 AI 助手；首次会弹出 4 步新手引导，可“跳过”，也可在助手头部点“使用指引”重看。
  3. 未配置大模型时，顶部状态为“AI 本地模式”，仍可用本地规则引擎演示全部核心指令。

四、API 配置方式（可选，接入真实大模型）
  1. 点击顶部“AI 本地模式”标签。
  2. 填入 Base URL、API Key、模型 ID（兼容 OpenAI 协议接口，如豆包 Ark / DeepSeek / Kimi / OpenAI）。
  3. 点“保存并测试”；测试通过后状态变为“AI 大模型在线”。
  注意：API Key 仅保存在本机浏览器 localStorage，不会写入文件或上传。

五、本地模式可演示范围
  - 拖拽整理：仓库 / 胸挂 / 口袋 / 背包 / 安全箱 / 装备槽之间移动与旋转、双击快速装备。
  - 三条核心指令（助手快捷指令或输入）：
     ① 帮我卖掉所有蓝色物品（出售确认弹窗）
     ② 帮我起装卡5w战备（配装 + 撤销）
     ③ 带入对局的高级子弹和甲修放保险（安全箱装载）
  - 自由口语：配装、放安全箱、按类别/品质/口径筛选、指定物品出售、修理、耐久检查等。
  - 交易行：购买物品、我的挂单（均为演示数据，非真实交易）。

六、演示步骤（离线本地模式）
  1. 双击 index.html → 看完新手引导（或跳过）。
  2. 打开助手 → 点“帮我卖掉所有蓝色物品”→ 勾选确认 → 观察余额变化。
  3. 点“帮我起装卡5w战备”→ 一键穿戴 → 右下角“撤销”恢复。
  4. 点“带入对局的高级子弹和甲修放保险”→ 观察安全箱。
  5. 顶部“交易行”→ 购买一件物品 → 查看“我的挂单”。

七、已知限制
  - 交易行与出售/挂单均为原型演示数据，不连接真实交易服务。
  - 未配置有效 API Key 时，自由输入由本地规则引擎解析，泛化能力有限；真实模型连通未验证。
  - 语音识别在 file:// 下不可用（需 HTTPS/localhost）。
  - 音效为 Web Audio 合成，需在浏览器内首次点击/按键后才会发声；浏览器限制时静默降级。
  - 请勿公开部署或上传含真实 API Key 的配置。
